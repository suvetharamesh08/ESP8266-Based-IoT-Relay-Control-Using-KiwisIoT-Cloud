# ESP8266-Based IoT Relay Control Using KiwisIoT Cloud

## 📌 Project Overview
This project demonstrates IoT-based relay control using an ESP8266 NodeMCU and KiwisIoT Cloud. It allows users to remotely switch a relay ON and OFF through cloud-based commands using a Wi-Fi connection.

## 🎯 Objectives
- Control a relay remotely using the internet.
- Connect ESP8266 to KiwisIoT Cloud.
- Implement wireless ON/OFF switching.
- Demonstrate IoT-based device automation.

## 🛠️ Components Required
- ESP8266 NodeMCU
- Single-Channel Relay Module
- Jumper Wires
- USB Cable
- Wi-Fi Connection


## ⚙️ Working Principle
1. ESP8266 connects to the Wi-Fi network.
2. KiwisIoT Cloud communication is established.
3. Relay control commands are received through Channel 1.
4. The relay switches ON or OFF based on the received command.
5. Connected electrical devices can be controlled remotely.
